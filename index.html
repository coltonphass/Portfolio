ezee-budget

Shared household budgeting, built as a PWA

▶ preview

Overview

A budgeting app my partner and I use to track shared household spending. It is a progressive web app, so it installs on a phone and works like a normal app without going through an app store.

Problem

We were tracking the household budget in a spreadsheet. It worked, but only one of us could sensibly edit it at a time, nothing updated live, and it was awkward to use on a phone, which is where you actually are when you are spending money.

  • Two people needed to add expenses from their own phones
  • Changes had to show up for both of us without a refresh or a re-share
  • It had to be quick to log something in a few seconds at a checkout

What it does

  • Logs shared expenses against categories
  • Tracks progress toward savings goals
  • Shows where the money actually went over a period
  • Installs to the home screen and keeps working offline

My role

Sole developer and designer. I picked the stack, built the UI in React and TypeScript, and used Supabase for the database, auth, and realtime sync so both of us see the same numbers at the same time. Styling is Tailwind.

Status

In active use by the two of us and still being worked on. It is not public yet because it is tied to our own data.

ReactTypeScriptSupabaseTailwindPWA

genesis-alphabetizer

Pulling every unique word out of a long text

▶ preview

Overview

A Python tool that reads the Book of Genesis, extracts every unique word in it, sorts them, and then checks each one for spelling accuracy.

Problem

Doing this by hand on a text that long is not realistic. The interesting part is not the reading, it is deciding what counts as a word: punctuation, capitalisation, and archaic spellings all have to be handled before you can say whether a word is unique or misspelled.

What it does

  • Reads and normalises the source text
  • Builds a sorted set of unique words
  • Checks each word against a dictionary and flags what fails

My role

Sole developer. Written in Python, no framework.

homelab

A Raspberry Pi running things I rely on

pi

Overview

A Raspberry Pi that sits on my network and runs Pi-hole for DNS level ad blocking, plus two Python Discord bots.

Problem

Browser based ad blockers only cover the browser, and only on the machine they are installed on. Running the block list at the DNS layer covers every device on the network, including phones and TVs that have no way to install an extension.

What it runs

  • Pi-hole, filtering DNS for every device on the network
  • Two Python Discord bots that need to stay online all the time

What I learned

Most of the value here was operational rather than code: how DNS resolution actually flows, keeping a service running across reboots and power cuts, and the fact that something only you maintain still needs to be maintained.

Raspberry PiPi-holePythonDNSLinux
